# 개인사업자 장기렌트 절세 계산기

2026\-08\-16 기준 대한민국 세법을 바탕으로 만든 **정적 HTML 계산기**입니다\.

## GitHub Pages에 올리는 방법

1. GitHub에서 새 저장소\(repository\)를 만듭니다\.
2. 이 폴더의 `index.html`을 저장소 최상위\(root\)에 업로드합니다\.
3. GitHub 저장소에서 **Settings → Pages**로 이동합니다\.
4. **Build and deployment → Source**를 `Deploy from a branch`로 선택합니다\.
5. Branch를 `main`, 폴더를 `/(root)`로 선택하고 저장합니다\.
6. 잠시 후 표시되는 GitHub Pages 주소로 접속하면 됩니다\.

별도 빌드, npm, 서버가 필요하지 않습니다\.

## 주요 계산 가정

- 개인사업자\(복식부기의무자\) 업무용승용차 특례 중심
- 일반 자동차대여사업자 장기렌트: 임차료 70%를 감가상각비 상당액으로 계산
- 감가상각비 상당액 연 800만원 한도\(일부기간 사용 시 월수 비례\)
- 운행기록 미작성 시 관련비용 연 1,500만원 기준\(일부기간 사용 시 월수 비례\)
- 종합소득세 \+ 개인지방소득세 표준세율 반영
- 정확한 과세표준 대신 선택 구간의 25%/50%/75% 지점으로 절세액 범위 산출
- 일반 승용차의 부가가치세 매입세액 공제는 반영하지 않음
